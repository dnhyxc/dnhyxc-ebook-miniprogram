# 中式传统色彩 · UI 配色方案

> 基于微信公众号中式传统色谱整理，提取四组适合现代界面设计的完整配色体系。
> 每组配色均使用 CSS 变量管理，可直接复制到项目中使用。

---

## 背景色推荐

从全部色谱中筛选出的最佳背景色候选项（低饱和度、高明度，视觉柔和不易疲劳）：

| 色名   | 色值      | 适用场景              |
| ------ | --------- | --------------------- |
| 無心綠 | `#BFD1B2` | 自然清新主题页面背景  |
| 清白   | `#CAC9BE` | 温润大地色调通用背景  |
| 月白   | `#D3E5EF` | 清爽蓝调页面背景      |
| 縹綠   | `#C1E2CF` | 浅薄荷绿卡片/浮层背景 |
| 瓷青   | `#AFDDE0` | 清雅青色卡片背景      |
| 玄天   | `#2E201D` | 暗色模式页面背景      |
| 月魄   | `#B2B6B6` | 暗色模式卡片/浮层背景 |

## 快速上手：CSS 变量模板

将以下代码复制到项目根样式中，即可全局使用：

```css
/* ===== 翠微新绿（默认） ===== */
:root {
  --bg-page: #bfd1b2;
  --bg-card: #c1e2cf;
  --bg-elevated: #d4ebdf;
  --ink-primary: #2e201d;
  --ink-secondary: #4a4548;
  --ink-tertiary: #576470;
  --ink-inverse: #cac9be;
  --primary: #1c2d29;
  --primary-hover: #2a4540;
  --accent: #dc541b;
  --accent-hover: #c44a18;
  --accent-light: rgba(220, 84, 27, 0.12);
  --success: #83ad28;
  --warning: #edac5d;
  --danger: #d64241;
  --info: #5b8b71;
  --border: #93bdad;
  --divider: rgba(147, 189, 173, 0.35);
  --shadow-sm: 0 1px 2px rgba(28, 45, 41, 0.06);
  --shadow-md: 0 4px 12px rgba(28, 45, 41, 0.08);
  --shadow-lg: 0 8px 24px rgba(28, 45, 41, 0.12);
}
```

多主题切换使用 `data-theme` 属性：

```css
[data-theme="blue"] {
  /* 东方既白 */
}
[data-theme="dark"] {
  /* 玄天黑土 */
}
[data-theme="warm"] {
  /* 十樣錦   */
}
```

## 使用建议

- **低饱和度大地色**（清白、無心綠、玄天）适合做背景色，高级感强，久看不累
- **绿色系 + 蓝色系**搭配可做新中式、自然主题设计
- **红色系**建议作为点缀/强调色（按钮、CTA、徽章），避免大面积使用导致视觉疲劳
- 暗色模式下用**金柔**做强调色比红色更优雅，避免刺眼
- 所有颜色均基于传统色谱提取，保持中式美学的温润质感
