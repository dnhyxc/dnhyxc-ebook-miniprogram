## 使用建议

### 1. 主题选型

- **亮色场景优先**：翠微新绿、东方既白、茶韵清烟、苔青幽谷、十樣錦、青蓮暮色
- **暗色场景优先**：玄天黑土、墨韵书香
- **高饱和 / 强视觉冲击**：珊瑚暖阳、琉璃金辉、十樣錦
- **低饱和 / 文艺气质**：翠微新绿、东方既白、茶韵清烟、苔青幽谷

### 2. 无障碍对比度

- 所有 `--ink-primary` 与 `--bg-page` 的对比度均需达到 **WCAG AA 4.5:1** 以上
- 暗色主题（玄天黑土、墨韵书香）中 `--ink-primary` 为浅色，反向对比
- 按钮文字与按钮背景的对比度也应满足 4.5:1
- 建议上线前使用 [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) 或 Chrome DevTools 的颜色对比度工具进行验证

### 3. 主题切换实现

推荐使用 CSS 自定义属性 + data 属性切换：

```html
<html data-theme="cuiwei"></html>
```

```css
/* 默认主题 */
:root {
  --bg-page: #bfd1b2;
  /* ... */
}

/* 通过 data-theme 切换 */
[data-theme="xuantian"] {
  --bg-page: #2e201d;
  /* ... */
}
```

### 4. 按钮使用规范

| 按钮类型               | 使用场景                                                           |
| ---------------------- | ------------------------------------------------------------------ |
| **主要 Primary**       | 页面唯一主操作（提交、支付、确认）                                 |
| **次要 Secondary**     | 辅助操作，与主要按钮并列但不希望抢夺注意力                         |
| **实心 Solid**         | 导航栏操作、工具栏按钮等需要视觉权重的场景                         |
| **幽灵 Ghost**         | 卡片内操作、列表项操作等轻量场景                                   |
| **成功 / 警告 / 危险** | 对应语义的确认操作（如"删除"用危险按钮）                           |
| **禁用 Disabled**      | 不可用状态，需配合 `cursor: not-allowed` 和 `pointer-events: none` |

### 5. 色值扩展

- 浅底色（`*-bg` 变量）适用于标签 (Tag)、徽标 (Badge)、提示条 (Alert) 的背景
- 边框浅色（`--border-light`）适用于卡片悬浮态、输入框聚焦边框的淡化态
- 阴影三档（sm / md / lg）覆盖从工具提示到弹窗的各种层级需求
- 如需新增色值，建议保持命名规范 `{类别}-{属性}-{变体}`
